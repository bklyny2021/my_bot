# Birthday Flyer - Project Summary

## What Was Created

A professional, poster-style birthday flyer in PDF format for a birthday celebration on **October 8** for someone born in **1968**.

## Files Added to Repository

1. **`birthday_flyer.pdf`** (2.5 KB)
   - The generated birthday flyer in PDF format
   - Letter size (8.5" x 11") for easy printing
   - Ready to share digitally or print

2. **`scripts/generate_birthday_flyer.py`** (4.1 KB)
   - Python script to generate the flyer
   - Uses ReportLab library for PDF creation
   - Fully customizable for future use

3. **`scripts/README_FLYER.md`** (1.5 KB)
   - Documentation for the flyer generator
   - Installation and usage instructions
   - Customization guide

## Flyer Details

### Design Elements
- **Color Scheme:** Red, Black, and White
- **Layout:** Poster-style with decorative borders
- **Decorations:** Red star symbols in corners
- **Banners:** Red title banner and black message banner

### Content
- **Title:** "BEE'S BIRTHDAY BASH!"
- **Date:** October 8
- **Birth Year:** 1968
- **Location:** Greenville, NC
- **Theme:** "A COOL GIGGLING CELEBRATION!"
- **Dress Code:** Wear Red, Black, or White
- **Contact:** bee@ok.com | 555-555-5555
- **Tagline:** "Let's party, laugh, and celebrate another trip around the sun!"

## How to Use

### View the Flyer
The PDF file `birthday_flyer.pdf` is ready to use. You can:
- Open it with any PDF viewer
- Print it on letter-sized paper (8.5" x 11")
- Share it digitally via email or social media

### Regenerate the Flyer
If you need to regenerate or customize the flyer:

```bash
# Install requirements (if needed)
pip3 install reportlab

# Run the generator script
python3 scripts/generate_birthday_flyer.py
```

### Customize the Flyer
Edit `scripts/generate_birthday_flyer.py` to change:
- Colors
- Text content
- Layout and spacing
- Fonts and font sizes
- Decorative elements
